# ✨ Glamora – Jewellery & Accessories E-Commerce Frontend

Glamora is a modern, elegant e-commerce frontend for browsing jewellery and accessories. It features a luxury-inspired user interface designed to provide a smooth and attractive shopping experience.

## 📌 Project Overview

Glamora is a React-based frontend project that showcases jewellery and accessories through a stylish product catalogue and shopping interface. The project focuses on responsive design, product discovery, and a premium shopping experience.

## ✨ Features

- **Luxury UI Design** – Elegant styling for a premium shopping experience.
- **Product Catalogue** – Browse jewellery and accessories.
- **Product Categories** – Explore products by category.
- **Product Details** – View product names, prices, descriptions, and images.
- **Product Badges** – Highlight selected products and offers.
- **Stock Information** – Display product availability information.
- **Responsive Styling** – Designed to work across different screen sizes.
- **Interactive Shopping Interface** – Explore the available products and navigate the storefront.

## 🛠️ Technologies Used
